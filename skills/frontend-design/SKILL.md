# FRONTEND DESIGN INTELLIGENCE // ANTI-SLOP STANDARD

## 1. Core Principle: Deliberate Aesthetic Intent
Never generate generic "AI template" websites. Every website must have an unmistakable, intentional personality tailored to its niche:
- **Zero "Default Tailwind" Slop:** No generic purple/indigo gradients on pure white cards.
- **Zero Inter Font Default:** Always pair distinctive typography (e.g. Syne, Plus Jakarta Sans, Fraunces, Cinzel, JetBrains Mono).
- **Surface Elevation Hierarchy:** Dark mode websites should not be flat black; use layered obsidian levels (#050709, #08090C, #12141A, #1A1D24) with 1px hairline translucent borders (rgba(255,255,255,0.08)).

## 2. Design Token System
- **Spacing:** Strict mathematical scale (4px, 8px, 16px, 24px, 32px, 48px, 64px, 96px).
- **Contrast:** Strict WCAG AAA compliance. All primary text must have at least 7:1 contrast ratio against the background.
- **Color Discipline (60-30-10 Rule):**
  - 60% Dominant Base (e.g. Pitch Obsidian Void)
  - 30% Structural Secondary (e.g. Deep Charcoal / Glass Surface)
  - 10% High-Voltage Accent (e.g. Electric Emerald #00FF66, Cyan Neon #00F0FF, Radiant Champagne #D4AF37).
