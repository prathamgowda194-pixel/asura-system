# UNIVERSAL RESPONSIVE ARCHITECTURE (REACT NATIVE & EXPO STANDARDS)

## 1. Mobile Touch Ergonomics
- All tap targets must be at least 44px x 44px to guarantee error-free mobile navigation.
- Use mobile drawer menus (bottom sheets / sliding navbars) for screens under 768px.

## 2. Fluid Layout System
- Mobile-first CSS media queries: w-full sm:w-1/2 lg:w-1/3.
- Fluid typography that scales seamlessly from phones to 4K displays.
