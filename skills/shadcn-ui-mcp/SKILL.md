# SHADCN / UI COMPONENT PROTOCOL

## 1. Core Component Primitives
When synthesizing modern web applications, integrate Shadcn-style components:
- **Modals / Dialogs:** Accessible backdrop with smooth opacity transition.
- **Tabs:** Animated pill switchers toggling active view panels.
- **Badges:** Small font-mono border tags for status indicators.
- **Cards:** Glassmorphic containers with header, description, content, and action footer.
