# Asura System Governance Directive: Strict Anti-Slop & Authentic Visual Taste

## 1. ABSOLUTE PROHIBITION ON PROCEDURAL PRIMITIVE 3D MESHES
- **NEVER** use procedural geometric primitives (`THREE.BoxGeometry`, `THREE.CylinderGeometry`, `THREE.SphereGeometry`, raw 2D canvas wireframes) to represent architecture, villas, vehicles, or consumer products.
- Primitive untextured meshes without high-polygon bevels, micro-surface normal maps, ray-traced shadows, and photorealistic PBR shaders look like broken AI slop and destroy visual taste.

## 2. AUTHENTIC 3D HOVER & MOTION DIRECTIVE
When building "3D hover effects", agents MUST use:
- **3D Card Perspective Tilt**: `perspective(1000px) rotateX(...) rotateY(...) scale3d(1.03)` with smooth spring dampening on pointer leave.
- **Dynamic Specular Light Glare**: A radial gradient overlay tracking mouse coordinates with `mix-blend-mode: overlay` that mimics a light source reflecting across a premium glass, stone, or metallic surface.
- **Multi-Plane Z-Depth Stacking**: Key elements (price badges, titles, buttons) elevated using `transform: translateZ(30px)` to create physical depth without primitive 3D meshes.
- **Card Transition Effects**: Smooth morphs, tabbed cross-fades, and velocity-inertia horizontal carousel dragging.

## 3. ZERO HEADER OVERLAP POLICY
- Fixed navigation bars and top docks MUST have safe top margins and background blur protection so they NEVER overlap headings, kickers, or hero content.

## 4. MINIMUM 5–6 SECTION ARCHITECTURAL DEPTH
Every generated website must be a comprehensive, full-length publication featuring:
1. Immersive Hero & Vision Statement
2. Curated Product / Property Quadrant Registry
3. Architectural Philosophy / The Craft & Materials Archive
4. Spatial / Interactive Walkthrough Chapters
5. Bespoke Amenities / Technical Specifications
6. Private Acquisition / Concierge Liaison Portal

## 5. ABSOLUTE PROHIBITION ON RAW UNICODE EMOJIS AS UI ICONS
- **NEVER** use raw unicode emojis (`⚓`, `🍷`, `🌊`, `🚁`, `⚡`, `🏠`, `🚀`, `🔥`, `✨`, etc.) in place of professional UI icons, amenity badges, buttons, or indicators.
- Emojis render inconsistently across operating systems, clash with editorial luxury typography, and are recognized by users as hallmarks of cheap AI slop.
- **Mandatory Practice**: Use crisp, stroke-based inline SVG vector icons (or Lucide icons) with uniform stroke weights (`1.5px`–`1.75px`), rounded line caps/joins, and curated theme palette fills.
